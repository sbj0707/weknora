# 评估方案开发任务清单

## 1. 目标与范围

参考知识库的界面和分层实现，完成「质量评估 → 评估方案」的配置管理，支持列表、搜索、新建、查看、编辑、删除和复制。方案保存在服务端数据库中，供后续模块使用。

### 已确认的约束

- 方案 ID 参考知识库，使用系统生成的 GUID；用户不能填写或修改，详情支持复制 ID。
- 暂不增加方案状态、版本及版本历史。
- 本次只管理方案配置，不调用模型生成 QA，不执行答案评估。
- QA 生成、QA 评估、评估对比三个模块不在本次开发范围内，已有导航入口保持现状。
- 本次不绑定知识库、文档、页码、Chunk 或 QA 数据集，也不配置被测知识库、智能体和被测模型。
- 不扩展知识库式的共享、收藏、置顶、导入导出功能。
- 菜单文字保持常规字重，页面复用现有设计令牌、组件和主题。

### 当前基础

- 已有「质量评估」菜单和四个分区的前端页面框架。
- 「评估方案」目前为占位内容，需要实现真实的数据管理。
- 现有 `/api/v1/evaluation` 用于启动评估任务和查询结果；本次新增独立的方案接口，不改变现有接口语义。

## 2. 字段设计

以下为本次实现的数据范围；表中的默认值和限制作为建议实现值，集中定义，便于后续调整。

| 页面字段 | 建议字段名 | 类型 | 必填及规则 |
| --- | --- | --- | --- |
| 方案 ID | `id` | GUID 字符串 | 系统生成，不可修改 |
| 名称 | `name` | 字符串 | 必填，去除首尾空白后不能留空；建议最多 100 字符 |
| 描述 | `description` | 多行字符串 | 可选；建议最多 1,000 字符 |
| QA 对生成提示词 | `qa_generation_prompt` | 多行字符串 | 必填，提供可编辑的默认模板 |
| 期望与实际答案对比提示词 | `answer_comparison_prompt` | 多行字符串 | 必填，提供可编辑的默认模板 |
| QA 生成模型 | `qa_generation_model_id` | 模型 ID | 必填，选择当前空间可用的文本生成模型 |
| 评估模型 | `evaluation_model_id` | 模型 ID | 必填，选择当前空间可用的文本生成模型，与生成模型分别保存 |
| 评分维度及权重 | `scoring_dimensions` | 结构化数组 | 至少一项，包含稳定的维度标识、名称、评分说明和权重；权重合计 100% |
| 通过分数 | `pass_score` | 数值 | 必填，范围 0～100；建议默认 80 |
| QA 生成规则 | `qa_generation_rules` | 结构化对象 | 保存每个片段生成数量、问题类型、难度、语言 |
| 创建人 | `created_by` | 用户 ID | 从登录身份获取，前端展示用户名称；客户端不可指定或修改 |
| 创建时间 | `created_at` | 时间 | 服务端维护，只读 |
| 更新时间 | `updated_at` | 时间 | 服务端维护，只读 |

存储层另保存 `tenant_id` 等必要的空间隔离字段，不作为用户可编辑的业务参数。删除采用项目现有的软删除约定；软删除标记不属于方案状态。

### 配置建议

- 默认评分维度：答案正确性、完整性、数字准确性、引用准确性；允许增删和调整说明、权重。
- 所有维度统一采用 0～100 分；提示词中的评分约定与页面设置保持一致。
- QA 生成规则建议默认每个片段生成 3 题，题型支持事实、数字、解释和综合，难度支持简单、中等、困难，语言默认中文。
- 题型允许多选，至少选择一项；每个片段生成数量必须为正整数，并设置合理上限。
- 本次不增加温度、输出长度、并发数、超时和重试次数等运行参数。
- 提示词变量使用明确的占位符，例如 `{{question}}`；编辑器保存原始文本，本次不渲染或执行。

### 建议接口

| 操作 | 方法 | 地址 | 行为 |
| --- | --- | --- | --- |
| 新建 | POST | `/api/v1/evaluation-plans` | 校验并返回新方案 |
| 列表 | GET | `/api/v1/evaluation-plans` | 按 ID、名称搜索，支持分页，默认按更新时间降序 |
| 详情 | GET | `/api/v1/evaluation-plans/:id` | 返回完整方案配置 |
| 编辑 | PUT | `/api/v1/evaluation-plans/:id` | 更新允许修改的配置字段 |
| 删除 | DELETE | `/api/v1/evaluation-plans/:id` | 软删除，不再出现在列表和详情中 |
| 复制 | POST | `/api/v1/evaluation-plans/:id/copy` | 基于原方案创建新记录 |
