# Native storage foundation

LocalFileStore migrates the physical Go provider layout: tenant/knowledge/unix-nanos.extension file uploads, tenant/exports/basename_timestamp.extension byte exports, legacy local:/ and storage:/ aliases, scoped wrappers, independent copies and external HMAC URLs. Writes are bounded and remove incomplete files. Caller-owned inputs are not closed. An added tenant-namespace guard prevents caller-supplied ../otherTenant namespaces, CREATE_NEW avoids overwrites, and symlink ancestors/leaf opens are rejected. These are deliberately stronger than Go's lexical-only path guard; a filesystem administrator changing an ancestor between check/open remains a separate operational trust boundary.

FileUrlSigner uses the deployment SYSTEM_SIGNING_KEY with SYSTEM_AES_KEY fallback, rejects unset/short/example keys, matches Go SHA-256 payload and query escaping/ordering/managed-key replacement, and never verifies unsigned URLs. The tenant path parser unwraps only canonical storage:// paths, scans the first uint64 segment including zero, and KB-export scope requires the adjacent exports namespace. It preserves Go's unusual URL assembly when APP_EXTERNAL_URL already contains query or fragment. Resource grant window truncation starts at Go year 1, not Unix epoch, and signs the window's whole Unix seconds. Different TTL windows can therefore share a token; an existing live row retains its original expiry.

ResourceCatalog uses the existing resources, resource_bindings and resource_access_grants tables, not new migrations. Registration deduplicates by owner tenant/location hash; stable raw-url 16-byte handles, provider/backend metadata and physical location hashing match Go. INSERT ON CONFLICT avoids aborting an enclosing PostgreSQL transaction on an expected duplicate. Resource resolution/mutations require the authoritative owner tenant (a stronger boundary than Go's internal unscoped Resolve); callers authorized through future shared-KB logic must supply the resource owner. Public DTO excludes physical_path/location_hash. Knowledge scope requires explicit binding joined to live owner-tenant knowledge and KB rows; mention-in-text alone grants no ownership. Message artifact access requires the exact message/artifact relation.

Release removes that owner's claims across all relations, then counts remaining bindings separately, preserving Go's behavior; legacy raw paths return -1. Deletion is a separate caller operation and must follow domain authorization and release. This foundation does not prove a complete atomic bind-vs-physical-delete protocol or implement domain deletion tasks. Grants store only token hashes, are strictly expiring and revocable, retain tombstones until expiry, reuse keyed derivation when possible and fall back to fresh random tokens. Possession of a live read token authorizes its resource, irrespective of the viewer's tenant. No HTTP /r route is connected yet.

ResourceFileStore is bound to one authorized resource-owner tenant. It registers files, original names/size/content hashes and temporary lifecycle; source-file binding and copy are compensated by physical deletion on failure. A joined business transaction also registers an after-rollback physical cleanup hook. External resource URLs issue read capabilities. MIME registration now uses the Go 1.26 built-in extension table and Unix database precedence: first readable globs2 file, otherwise all mime.types files, exact-before-lowercase extension lookup, existing built-in priority in globs, and last-entry overwrite in types files. OriginalName follows Unix filepath.Base including empty/absolute/trailing-slash cases. MIME is extension-derived, with text charset=utf-8 matching Go; no content sniffing is applied. Parameter parsing reproduces Go's unusual empty MIME result for a text type with pre-existing parameters and no nonempty charset. Windows registry augmentation is not implemented; the current Docker target is Unix. Runtime results intentionally follow the target host MIME database; the oracle stores the Go host database snapshot for reproducibility. Go MIME data and parsing attribution is retained in GO-MIME-LICENSE.txt. Mixed/provider-sharing copy requires later domain authorization support.

StorageResolver reads an existing KB's immutable owner/binding and preserves concrete backend, requested-provider legacy alias, tenant default, legacy JSON and environment fallback precedence. Go's legacy alias resolution can select a disabled alias; explicit/default disabled IDs fail. Native factory supports local only. Other providers explicitly fail before external writes, rather than silently mapping a cloud binding to local. Storage allow-list CRUD, encrypted cloud configuration and connectivity tests are not migrated by this resolver. It does not auto-create filesystem directories at startup or database tables.
