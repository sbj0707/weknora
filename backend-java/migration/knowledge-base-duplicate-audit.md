# 知识库配置复制：实施前审计（历史）

此文保留实施前审计。当前已新增原生实现并完成限定范围对照，状态为 in_progress；见 [实现与验证范围](knowledge-base-duplicate-notes.md)及 [checkpoint](knowledge-base-duplicate-checkpoint-2026-10-16.json)。

`POST /api/v1/knowledge-bases/:id/duplicate` uses Contributor and KB-read middleware plus the management API-key gate. The handler independently requires the source owner to equal the original caller tenant, so a shared source still fails with `No permission to duplicate this knowledge base`. It returns 201 with source_id, target_id, message and a decorated knowledge_base response.

The service trims the source ID and reads it under the execution tenant. It clones through the production KB's JSON marshal/unmarshal, not SQL row copying. This invokes credential redaction and request JSON's legacy provider fallback, which differs from move-target database reads. Then it clears GeneratedProfile, runtime counts/processing/share/creator display state, pin/deletion/temporary state; assigns a new UUID, creator only for a nonsynthetic user, tenant and current timestamps; applies defaults and normalization; validates a retained vector-store binding; creates the KB and best-effort activity audit. It does not copy documents, chunks, indexes, FAQ content, Wiki pages, shares or personal pins, and enqueues no clone task.

Name generation uses caller language: zh ` 副本`, ko ` 사본`, ru ` копия`, otherwise ` Copy`, with localized empty-name fallback. It compares names of live non-temporary tenant KBs and appends ` 2`, ` 3`, etc. A failed list lookup falls back to the first copy name. This is not a call to generic Java create: create's payload validation, credential handling, side effects and error behavior need to be compared explicitly.

Sources: `internal/handler/knowledgebase.go` DuplicateKnowledgeBase; `internal/application/service/knowledgebase.go` DuplicateKnowledgeBase, buildDuplicateKnowledgeBaseName, cloneKnowledgeBaseConfiguration and validateVectorStoreBinding; `internal/types/knowledgebase.go` MarshalJSON/UnmarshalJSON/Normalize; `backend-java/src/main/java/com/tencent/weknora/knowledge/KnowledgeBaseLifecycle.java` existing create/bindings as potential reusable pieces. Next step is an actual Go HTTP and persisted SQL oracle, including shared/API-key denials, locales/name collisions, credentials/provider fallback, retained bindings, synthetic actor/audit and absence of content/queue side effects.
